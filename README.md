### Текст задачи

Дан дек D и список L. Каждый исходный контейнер содержит не менее 5 элементов. Вставить перед пятым с конца элементом списка последние 5 элементов дека в обратном порядке. Использовать один вызов функции-члена insert.

# Задание 3

## Задача 3

### Текст задачи

Дан список L и вектор V; список L имеет нечетное количество элементов. Переместить средний элемент списка L в конец вектора V. Использовать функции-члены push_back и erase.

### Алгоритм решения

Считываем элементы для списка и вектора. Чтобы найти середину списка (так как списки не поддерживают произвольный доступ), используем функцию `std::advance`, сдвигая итератор от начала на `size() / 2`. Значение по этому итератору добавляем в конец вектора через `push_back`, после чего удаляем этот элемент из списка с помощью `erase`.

# Задание 5

## Задача 4

### Текст задачи

Дан список L. Удалить все элементы списка, расположенные между первым и вторым отрицательным элементом (не включая сами отрицательные элементы). Если список не содержит отрицательных элементов, то не изменять его, если отрицательный элемент всего один, то удалить все элементы, следующие за этим отрицательным элементом. Использовать два вызова алгоритма find_if и один вызов функции-члена erase.

### Алгоритм решения

Используя алгоритм `find_if` с лямбда-выражением, ищем первый отрицательный элемент. Если его нет, завершаем работу. Если он найден, повторно вызываем `find_if` для поиска второго отрицательного элемента. Если второй элемент не найден, удаляем всё от первого отрицательного до конца списка через `erase`. Если найден — удаляем диапазон между первым и вторым отрицательными элементами.

# Задание 8

## Задача 2

### Текст задачи

Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Количество элементов дека D должно быть на 1 меньше количества элементов списка L. Например, для исходного списка ABC, DEF, KLM, XYZ полученный дек должен содержать строки AF, DM, KZ. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для дека D.

### Алгоритм решения

Инициализируем список строками. Для заполнения дека используем алгоритм `adjacent_difference` с итератором вставки `back_inserter` и лямбда-выражением. Лямбда берет первую букву предыдущего слова и последнюю букву текущего, объединяя их. Поскольку `adjacent_difference` копирует первый элемент как есть, размер дека получается равным размеру списка, поэтому первый элемент удаляем с помощью `erase`, чтобы выполнялось условие задачи.

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, ..., VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, ..., VN. Найти количество векторов V1, I = 1, ..., N, в которых содержатся все элементы вектора V0 (без учета их повторений). Использовать алгоритм includes, применяя его в цикле к двум множествам, одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов V1, I = 1, ..., N.

### Алгоритм решения

Считываем эталонный вектор V0 и создаем на его основе контейнер `std::set`, который автоматически удаляет повторяющиеся элементы и сортирует их. В цикле считываем остальные N векторов, также преобразуя их в множества. С помощью алгоритма `std::includes` проверяем, содержит ли текущее множество все элементы эталонного. Подсчитываем количество успешных проверок.

# Задание 10

## Задача 1

### Текст задачи

Дан вектор V. Определить количество повторений каждого числа в векторе V и вывести все различные элементы вектора V вместе с количеством их повторений (в порядке возрастания значений элементов); количество повторений выводить сразу после значения соответствующего элемента. Использовать вспомогательное отображение M (класс map), ключами которого являются различные элементы вектора V, а значениями — количество повторений этих элементов. При заполнении отображения M не использовать условные конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при заполнении отображения M) и элементы отображения M (при выводе полученных результатов) перебирать в цикле с параметром-итератором соответствующего контейнера.

### Алгоритм решения

Считываем элементы вектора. Создаем контейнер `std::map`, где ключом будет число, а значением — счетчик. В цикле с итератором проходим по вектору и для каждого элемента выполняем инкремент `M[*it]`. Благодаря особенности `std::map`, если ключа еще нет, он создается автоматически со значением 0, поэтому условные операторы не нужны. При выводе `map` автоматически сортирует элементы по возрастанию ключей. Проходим по нему итератором и выводим ключ и значение.
